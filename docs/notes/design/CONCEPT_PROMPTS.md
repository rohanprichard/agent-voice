# Canvas concept prompts

Date: September 23, 2026.

The built-in image generator created these concept images.
These prompts record the generation inputs, not implemented behavior.
The images are proposals for discussion.

## Canvas, first version

```text
Use case: ui-mockup. Create one high-fidelity concept image for TalkToMe, a macOS voice interface for an existing AI agent. This is an original product design exploration, not a website, poster, or working screenshot. Use clear, readable UI text. Show practical controls, an agent connection, and a visible transcript. No permanent sidebar, no chat bubbles, no slogans, no feature-card grid, no giant glowing orb. Keep text high contrast. Use a front-on view, with no perspective distortion. The image is for preview only.
Concept C: Canvas. Create a landscape design board with the small heading "03 / CANVAS" and a small badge "Future screen tools". Show one macOS app window in a dark theme. The app has an ink-blue frame, near-black work surface, warm white text, and pale chartreuse annotation accents. Show a useful shared work surface, not a chat interface. A large central canvas holds a light document titled "Interface notes". Its three short lines read "One place to talk", "A transcript when needed", "Controls within reach". An agent annotation draws a thin hand-drawn chartreuse oval around the last line, with a short arrow and label "Keep these together". A floating compact transcript card occupies a lower corner without covering the document. Its text reads "You" / "Which part needs work?" and "Agent" / "Keep the controls beside the transcript." A compact floating voice dock sits along the bottom center, with a little wave trace, "Agent connected", "Mute", "Transcript", and "End". A visible top strip says "Screen shared" and has a "Stop sharing" button. Include small History and Settings icons at the top. No sidebar. The canvas and conversation share one space. The image must clearly look like a proposal for future screen annotation tools, not a claim that these tools already work. Strong typography and exact alignment. The annotation is a functional mark, not decoration. The small floating dock should feel related to a desktop companion. Avoid sci-fi HUDs, glows, excessive glass, code wallpaper, and marketing text.
```

## Canvas / Ivory

```text
Use case: ui-mockup.
Asset type: preview concept for a macOS app called TalkToMe.
Primary request: An elegant, highly refined Canvas interface for speaking with an existing AI agent. The user wants the presence and character of a luxury instrument, with the usability of a simple native Mac app. Create a real, buildable interface, not a luxury advertisement. The distinctive feature is a very thin voice line that becomes the agent's annotation stroke. The work is the center. No chat shell or permanent sidebar.
Composition: one large front-on desktop app window fills 92 percent of a landscape image. Use small margins outside the app. No physical desk, plants, watches, books, metal objects, or decorative props. No inset windows. No collage. No slogans. The top margin outside the window has only the concept name and "Future screen tools".
Layout: narrow top app bar with macOS traffic lights, a refined serif wordmark "TalkToMe", and small History and Settings icons. A quiet second row has the session title "Review the homepage", an agent dropdown labeled "Agent connected", and a visible "Screen shared" label with "Stop sharing". Keep these readable.
The bounded work surface takes most of the window. Inside it, show a shared browser capture like a flattened sheet, clearly labeled "Browser capture". The browser content is a restrained project page with the heading "A clearer first step", two short lines of body text, and one button labeled "Start". Use typographic content, not photography. Put a fine agent-drawn oval around the Start button. An elegant narrow arrow connects the oval to a short annotation "Keep one clear action". The annotation has a small "Agent" attribution so it cannot be confused with the user's cursor.
Below the capture, but inside the main work surface, show a shallow opaque transcript sheet. It has a "Transcript" label, a collapse icon, and two readable entries: "You" / "What should we simplify?" and "Agent" / "Keep one clear action. Move the other options into settings." Transcript does not cover the target or annotation.
At the bottom, use a slim floating control dock. It contains a tiny voice line, "Listening", a microphone control labeled "Mute", a text field labeled "Type a message", a button labeled "Interrupt", and a discrete red control labeled "End". Make controls comfortably sized. The canvas fills available space. No huge empty central void. No visual clutter.
Typography: refined editorial serif for the wordmark and session title only. Precise contemporary sans-serif for all controls and transcripts. Clear hierarchy, exact baseline alignment, strong text contrast.
Avoid: neon, sci-fi HUD, glowing orbs, excessive glass, thick shadows, faux gold foil, marble, ornamental borders, tiny low-contrast labels, marketing copy, extra navigation, and generic dashboard grids. No actual screen control is implemented. This image represents a future-state proposal.
Concept name: "CANVAS / IVORY".
Color and material: warm ivory shell, pale limestone work surface, crisp off-white browser sheet, dark espresso text. Use muted oxblood for the voice line and agent annotation. Borders are fine, warm gray. The dock uses deep espresso with ivory text. The transcript sheet uses solid ivory with a fine top rule. Shadow is minimal and natural. The total effect should feel like an exquisitely typeset architectural folio, with quiet confidence and generous but disciplined spacing. No giant title. The product must feel sophisticated and calm.
```
